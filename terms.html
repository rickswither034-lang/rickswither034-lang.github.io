Условия использования

Назначение

Mail Digest n8n — личная автоматизация для чтения почты владельца, подготовки AI-сводки и её отправки в собственный Telegram-чат. Публичный сайт предоставляет описание проекта. Регистрация сторонних пользователей и коммерческое обслуживание через сайт не предлагаются.

Точность отчётов

Сводка создаётся автоматически и может содержать ошибки, пропуски или неточную оценку срочности. Владелец проверяет сведения, сроки и рекомендуемые действия по оригинальным письмам. Отчёт не заменяет профессиональные консультации или самостоятельную проверку важных решений.

Подключения и расходы

Владелец управляет разрешениями Google и учётными данными Telegram и OpenAI. Для работы необходимы действующие подключения и работающий VPS. Использование VPS и OpenAI API может оплачиваться по тарифам соответствующих поставщиков. Этот сайт не принимает платежи и не оформляет подписки.

Остановка и изменение

Автоматизация может быть остановлена или изменена владельцем через n8n. Работа зависит от доступности сторонних API и действительности разрешений. Условия обработки данных изложены в политике конфиденциальности.
