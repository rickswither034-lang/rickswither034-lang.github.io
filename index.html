Mail Digest n8n

Личный инструмент владельца Gmail для ежедневной сводки новых писем в Telegram. Автоматизация работает в n8n на собственном виртуальном сервере владельца.

Как работает отчёт

  1. По расписанию получает новые письма Gmail с разрешением только на чтение.
  2. Передаёт отобранные поля писем в OpenAI API для подготовки краткой сводки.
  3. Отправляет готовый отчёт владельцу через его Telegram-бота.

Отчёт помогает выделить срочные и важные письма и объединить рассылки. Классификация может содержать ошибки: важные сведения и сроки следует проверять в оригинальных письмах.

Доступ и данные

Проект предназначен для личного использования владельцем. Этот публичный сайт содержит только описание проекта и документы; почта через него не загружается, и доступ к интерфейсу n8n он не предоставляет.
