Политика конфиденциальности

Эта политика описывает обработку данных личной автоматизацией Mail Digest n8n. Она предназначена для владельца подключённого почтового ящика, а не для массового обслуживания сторонних пользователей.

Какие данные обрабатываются

С разрешения владельца автоматизация читает новые письма Gmail: отправителя, тему, дату, идентификатор и доступный текстовый фрагмент. Разрешение Gmail — gmail.readonly. Оно не предоставляет права отправлять, изменять или удалять письма.

Цель обработки и получатели

Данные используются для подготовки и доставки ежедневного отчёта. Отобранные поля и фрагменты писем передаются в OpenAI API для анализа. Итоговая сводка передаётся в Telegram для доставки владельцу через его бота. Обработка на сервере выполняется в собственном экземпляре n8n владельца; инфраструктуру VPS предоставляет F3 Cloud.

Текущая обработка исключает текстовые фрагменты писем от F3 Cloud и уведомлений, распознанных как связанные с паролями, кодами входа и безопасностью. Полные тела писем и вложения не включаются в запрос к модели. Фильтрация может быть несовершенной, поэтому фрагменты другой личной переписки могут попасть в запрос OpenAI.

Данные Gmail не продаются, не используются этой автоматизацией для рекламы и не используются владельцем проекта для обучения обобщённых моделей искусственного интеллекта.

Хранение и защита

Учётные данные подключений хранятся в n8n на VPS; n8n шифрует значения подключений ключом экземпляра. База данных, настройки и резервные копии могут храниться на VPS до удаления владельцем. Отчёты сохраняются в Telegram-чате согласно настройкам и условиям Telegram. Сроки обработки и хранения у Google, OpenAI, Telegram и хостинг-провайдера регулируются также их собственными правилами.

Файлы этого публичного сайта не содержат писем, токенов и паролей. GitHub Pages может обрабатывать обычные технические сведения о посещении согласно своей политике конфиденциальности; собственная аналитика на сайте не установлена.

Контроль владельца

Владелец может остановить workflow в n8n и отозвать доступ через настройки подключений аккаунта Google. Удаление локальных данных и резервных копий выполняется владельцем отдельно; отзыв доступа Google сам по себе не удаляет ранее подготовленные отчёты.

Правила Google

Использование и передача информации, полученной через Google API, ограничиваются описанной функцией почтовой сводки и должны соответствовать Google API Services User Data Policy, включая требования Limited Use.

Вопросы и изменения

Настройками обработки управляет владелец проекта. Вопросы об этой личной автоматизации можно направить через профиль владельца проекта на GitHub. При изменении состава передаваемых данных или получателей эта политика должна быть обновлена.
